# p2_dataset — 数据工程（路线图 ②）

AI 流程的**起点**。模型的能力上限由数据决定——"有多少人工，就有多少智能"，本层负责把原始语料加工成能喂给微调的结构化数据集。

> **文件角色**：本 README 只做概括提炼与导航；每个小节的**完整教学 + 课后练习**都在小节自己的 `README.md` 里。

## 流程位置

- **上游**：无（起点）
- **下游**：`p4_finetune` —— 本层产出的数据集是微调的训练输入

## 本层重点提炼

- **核心原则**：训练数据 = 希望模型学会的行为 → 清洗标准、构造标准都由下游目标决定
- **数据策展三要素**：数量、覆盖度、质量——少量高质量 > 大量含噪，多样性是提性能的关键
- **视角**：本层是"以数据为中心的 AI"（data-centric），靠优化数据用更少资源训出更好模型
- **为什么难**：标注难 → 定标注指南更难 → 自动生成数据难 → **自动验证质量最难**（所以有专职数据岗位）

### 三个训练阶段的数据格式总表（考点）

| 训练阶段 | 数据格式 | 数据量衡量 | 本层对应小节 |
|---|---|---|---|
| 预训练 | 序列文本（自监督） | token 数 | `p1_corpus`（只做概念 + 清洗练习） |
| 监督微调 SFT | （指令，响应） | 样本数 | `p2_instruction`（核心动手节） |
| 偏好微调 DPO | （提示词，胜出响应，落败响应） | 样本数 | `p3_preference`（选学） |
| 奖励模型 | 偏好格式，或 （（指令，响应），分数） | 样本数 | `p3_preference` |

## 子目录导航

| 子目录 | 内容 | 教学/练习入口（见小节 README） |
|---|---|---|
| `p1_corpus/` | 语料采集与清洗 | 知识：五维度分类、变换在前判等在后、去重三级、工具阶梯；练习 1（难度 2/5） |
| `p2_instruction/` | 指令对构造（SFT 数据） | 知识：SFT 格式、output=行为、合成数据、质检；练习 0/2/3（**验收**）/4 |
| `p3_preference/` | 偏好对构造（DPO 数据）【选学】 | 知识：DPO 格式、标注指南；练习 5 |

## 练习路径（先单点、后贯通）

1. **单点**：`p1_corpus` 练习 1（清洗）→ `p2_instruction` 练习 0/2（格式与构造）
2. **贯通（本层验收）**：`p2_instruction` 练习 3——100 条指令对，汇总 p1 的清洗能力和 p2 的构造能力，`datasets` 可加载即通过
3. **选学**：`p3_preference` 练习 5（依赖练习 4 的合成产物）

交作业统一格式：`.py` 放对应小节目录 + 发控制台输出 + 说踩坑点。

## 学习深度要求

- **必须动手**：亲手构造 100 条指令对（Excel → JSONL），验收标准是能被 `datasets` 库加载
- **概念即可**：预训练语料的规模量级、工业级清洗去重流程
