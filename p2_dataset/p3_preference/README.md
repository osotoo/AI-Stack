本节是选学：DPO（偏好对齐）的数据准备。建议推迟到 `p4_finetune` 真正做 DPO 时再回来，原料可以直接复用 `p2_instruction` 练习 4 的合成产物。

## 一、知识学习

### DPO 数据格式（考点）

偏好微调需要"提示词、胜出响应、落败响应"三元组，数据量按样本数衡量。JSONL 每行一条：

```json
{"question": "怎么退换货？", "chosen": "分步说明：1. 先在订单页…… 2. ……", "rejected": "去订单页面看看。"}
```

### 奖励模型的数据格式

训练奖励模型（RM）可以用两种格式：和 DPO 一样的偏好格式，或者"（指令，响应），分数"的带分标注格式。

### 标注：人是裁判

`chosen` 和 `rejected` 由人标注：同一个问题收集 2 到 3 个不同质量的回答，人来判断优劣。

动手标注之前，先写标注指南——什么样的回答算胜出？这件事比标注本身更难。数据工作的难度递进是：标注难，定指南更难，自动生成数据难，自动验证质量最难。造档差有个常用手法：同一问题让模型分别生成"详细分步"和"一句话敷衍"两个版本，质量差距天然拉开。
