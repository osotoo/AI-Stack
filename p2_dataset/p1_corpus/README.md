# p1_corpus — 语料采集与清洗

客服系统导出的一份 `raw_corpus.csv`，30 条数据里什么都有：空行、重复、手机号、身份证号、HTML 标签、乱码。这种东西直接拿去训练，模型学到的第一件事就是垃圾。本节解决两个问题：这批数据怎么洗干净，以及"洗数据"背后的方法论——它在所有 AI 数据工作里通用。

动手前只需要一件事：会在 IDEA 里运行 `.py` 文件。pandas 和正则用到哪儿，练习里教到哪儿——练习区是一架六级台阶，从照着跑到独立写，零基础也能一级级上。学完本节你能独立写出一条可复用的清洗流水线，搬到任何文本语料上。洗出来的 `clean_corpus.csv` 不是终点，它是下一节指令对构造的取材来源。

## 一、知识学习

### 语料从哪来（概念）

本节标题里有"采集"两个字，先交代语料的三条常见来路：业务系统导出（客服工单、商品评论——本节的 `raw_corpus.csv` 就是这类）、公开数据集（Hugging Face、各机构发布）、自己爬取。来路决定清洗重点，也决定合规边界：爬来的先想版权和隐私，导出的先想脱敏。

### 清洗标准由下游决定（核心）

清洗不是洁癖。同一份语料，下游不同，洗法完全不同：

| 下游 | 清洗重点 | 噪声容忍度 |
|---|---|---|
| 预训练语料 | 去重、规模 | 高：海量数据容得下少量噪声 |
| SFT 指令对 | 逐条把关，宁缺毋滥 | 低：一条坏样本就能教坏模型 |
| RAG 知识库 | 切分友好、事实准确、脱敏彻底 | 中 |

一句话收尾：训练数据等于希望模型学会的行为，所以清洗标准就是下游目标对数据的要求。本节数据的下游，是下一节的指令对构造。

### 五个维度，但不是五件平行的事（考点）

去空、去重、脱敏、去噪、统计报告——把这五个词背下来没用，要看穿每个动作的本质：它是"改"文本，是"删"行，还是"记账"。

| 维度 | 操作性质 | 说明 |
|---|---|---|
| 去空 | 结构修复 | 缺失值处理；`NaN` 和纯空白字符串是两回事，判法不同 |
| 去噪 | 变换 | 改文本不删行：HTML 标签、乱码、表情、连续空白 |
| 脱敏 | 变换 | 改文本不删行：手机号、身份证、邮箱换成占位符 |
| 去重 | 判等 | 比较文本、决定删行；分精确、近似、语义三级 |
| 统计报告 | 贯穿 | 不是最后一步。每步之后记一行账：洗了几条，按什么规则 |

工业级清洗还有扩展维度：格式统一（编码、全半角、繁简）、长度过滤、质量打分、违规内容剔除。

### 处理顺序：变换在前，判等在后（考点）

顺序不是口味问题，直接决定结果。看原料里真实存在的两条：

```text
充电线用了一周就接触不良，质量太差了。    ← id=14
充电线用了一周就接触不良，质量太差了      ← id=23，末尾多一个空格
```

先去重：两条都留下，因为字节不同，精确去重抓不到。先去噪把尾随空白干掉、再去重：只剩一条。脱敏同理——两条文本如果只差手机号不同，先脱敏再去重就能抓到。

所以顺序定死为：**去空最先，变换（去噪、脱敏）在前，判等（去重）在后，统计贯穿全程。** 去空为什么最先？pandas 读进来的空字段是 `NaN`，后面的字符串操作一碰就崩。另外注意 `NaN`、空字符串、纯空格、全角空格是四种不同的东西，各有各的判法。

### 去重的三级火力（考点）

一字不差的重复好抓，真正麻烦的是"看起来不一样"的重复：

| 层级 | 方法 | 抓得住 | 抓不住 |
|---|---|---|---|
| 精确 | 哈希、set、`pandas.duplicated` | 一字不差 | 一字之差、洗稿 |
| 近似 | n-gram Jaccard、SimHash | 改几个字的洗稿 | 同义改写 |
| 语义 | embedding 向量相似度 | 换说法的复述 | 成本高，阈值难调 |

工业级预训练语料用 MinHash 加 LSH（Python 生态的标准库是 `datasketch`）：不做两两比对，牺牲少量召回换可扩展性。

### 脱敏：从正则到模型

格式固定的敏感信息（手机号、身份证、邮箱、银行卡）一条正则就能抓干净。姓名、地址这类没有固定格式的个人信息，规则写不全，要用 NER 模型识别，代表工具是微软 Presidio 和 HanLP。脱敏不是技术洁癖——《个人信息保护法》摆在那里，这是合规要求。

### 统计报告：清洗的账本

清洗不可回溯就是事故：原始数据永远保留，清洗产物另存。统计报告写三样东西：

1. 总量变化：30 条进来，22 条出去
2. 分类计数：每条规则洗掉多少
3. 抽样示例：每类抽 2 条，肉眼确认规则没有误伤

"账本"这个比喻到"要人工记账"为止——账不会自己记，每一步统计代码就是记账动作。

### 表格在 pandas 眼里的样子（考点）

CSV 读进来的那个 DataFrame，在内存里按列摆放：每列一个名字带一摞值。整列操作快、逐行遍历慢，根源都在这。由此有三个直接后果：

1. `for row in df` 遍历得到的是列名，不是行。要逐行拿数据，显式调用 `iterrows()`
2. `"充电线"[1]` 取的是字符"电"。下标取什么，取决于它作用的对象是什么类型——动手前先问自己"这个变量装的是什么"
3. 所谓"一行"，是取数时把三列同一位置的值现拼出来的，存储里没有现成的行

本节练习的站 1 就是围绕这三条训练的。

### 工具阶梯：先写熟 L1，认识 L2 到 L4

| 层级 | 工具 | 定位 |
|---|---|---|
| L1 必须动手 | Python `re` 正则、pandas、Excel 肉眼核对 | 本节练习的主力 |
| L2 装着玩 | `chardet`（编码检测）、`langdetect`（语言识别）、`datasketch`（MinHash 近似去重） | 加练项 |
| L3 知道即可 | OpenRefine（交互清洗 GUI）、Great Expectations（数据质量断言）、cleanlab（标注质量检测） | 系统级工具的定位 |
| L4 面试谈资 | data-juicer（阿里开源 LLM 数据处理系统）、Dingo（LLM 语料质量规则）、NeMo Curator（NVIDIA） | 工业级语料管线 |

本仓库的边界：L1 写熟，L2 装着玩，L3 和 L4 概念即可。

### 站 2：从看懂到写出

**动作一，仿跑。** 先读，再手打（不许复制粘贴），存成 `warmup_empty.py` 运行：

```python
# -*- coding: utf-8 -*-
# warmup_empty.py —— 去空：把 text 为空或纯空白的行丢掉
import pathlib

import pandas as pd

# __file__ 是脚本自己的路径，parent 是它所在的目录。
# 用它拼出 CSV 路径，脚本无论从哪个目录启动都找得到数据文件。
csv_path = pathlib.Path(__file__).parent / "raw_corpus.csv"
df = pd.read_csv(csv_path)

print("去空前：", len(df), "条")

# mask 是一个普通列表：第 i 个格子记录第 i 行要不要留（True 留，False 丢）。
mask = []

# iterrows() 按行遍历表格：每一轮 i 是行号，row 是这一行的内容。
for i, row in df.iterrows():
    text = row["text"]  # 按列名取文本，不会错位

    # or 从左往右算，左边成立就不再看右边（短路）。
    # NaN 是 pandas 表示空字段的值，没有 strip 方法，必须先判它。
    # strip() 去掉首尾空白，半角空格和全角空格都算空白。
    if pd.isna(text) or text.strip() == "":
        mask.append(False)  # 空行，标记为丢
    else:
        mask.append(True)  # 有内容，标记为留

# 用 mask 筛行：True 的行留下，False 的行丢掉。
df = df[mask]

print("去空后：", len(df), "条")  # 预期 27：30 减去 3 条空白
```

### 站 3：招式训练场

先认识一张小表。它是知识部分"五个维度"的代码版：去空是筛行，去噪、脱敏是变换，去重是判等，统计是记账。要背的是这五行，不是 pandas 的几百个函数：

| 需求长这样 | 招式 | 本章的例子 |
|---|---|---|
| 满足条件的行不要了 | 布尔筛选 `df[mask]` | 去空、删手机号行 |
| 行要留，文本要改 | 列变换 `.str.replace`、`.str.strip` | 脱敏、去 HTML |
| 判断哪些行是重复的 | `.duplicated()` 判等再删 | 去重 |
| 空字段、缺失值 | `pd.isna` 判、`fillna` 补 | id=3 的 NaN |
| 数条数、分类计数 | `len(df)`、`.value_counts()` | 统计报告 |
