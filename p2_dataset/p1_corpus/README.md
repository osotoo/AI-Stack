# p1_corpus — 语料采集与清洗

**本节定位**：AI 流程最上游的实操节。任务：把 `raw_corpus.csv`（30 条电商客服脏语料）洗成干净语料，产出清洗脚本 `p1_clean.py` + 统计报告。下游是 `p2_instruction`（清洗过的语料是构造指令对的原料）。

## 一、知识学习

### 1.1 清洗标准由下游目标决定（核心）

"数据清洗按项目目标前进"的具体含义——同一份语料，下游不同，洗法不同：

| 下游 | 清洗重点 | 噪声容忍度 |
|---|---|---|
| 预训练语料 | 去重、规模 | 高（海量数据容忍少量噪声） |
| SFT 指令对 | 逐条把关，宁缺毋滥 | 低（一条坏样本教坏模型） |
| RAG 知识库 | 切分友好、事实准确、脱敏彻底 | 中 |

原则：训练数据 = 希望模型学会的行为 → **清洗标准 = 下游目标对数据的要求**。

### 1.2 五个维度按"操作性质"分类（考点）

去空、去重、脱敏、去噪、统计报告不是平行的五件事：

| 维度 | 操作性质 | 说明 |
|---|---|---|
| 去空 | 结构修复 | 缺失值处理；`NaN` 和纯空白字符串是两回事，判法不同 |
| 去噪 | **变换** | 改文本不删行：HTML 标签、乱码、表情、连续空白 |
| 脱敏 | **变换** | 改文本不删行：手机号/身份证/邮箱 → 占位符（合规要求） |
| 去重 | **判等** | 比较文本、决定删行；精确 → 近似 → 语义 三个层级 |
| 统计报告 | **贯穿** | 不是最后一步！每步之后记一行账：洗了几条、按什么规则 |

工业级还有扩展维度：格式统一（编码/全半角/繁简）、长度过滤、质量打分过滤、违规内容剔除。

### 1.3 处理顺序原则（考点）

**变换在前，判等在后，统计贯穿，去空最先。**

- 去空最先：pandas 里 `NaN` 会让所有字符串操作崩溃。注意区分：空字段读进来是 `NaN`，纯空格字段是 `"   "`（字符串），全角空格 `U+3000` 也是字符串——三种判法不同
- 变换（去噪、脱敏）在判等（去重）之前，否则抓不全：
  - id=14「…质量太差了。」vs id=23「…质量太差了␣」（尾随空格）：先去重抓不到，**先去噪再去重就抓到了**
  - 两条文本只差手机号不同：先脱敏再去重就抓到了
- 每步记账：这就是统计报告

### 1.4 去重的三个深度层级

| 层级 | 方法 | 抓得住 | 抓不住 |
|---|---|---|---|
| 精确 | 哈希 / set / `pandas.duplicated` | 一字不差 | 一字之差、洗稿 |
| 近似 | n-gram Jaccard、SimHash | 改几个字的洗稿 | 同义改写 |
| 语义 | embedding 向量相似度 | 换说法的复述 | 成本高、阈值难调 |

工业级预训练语料用 **MinHash + LSH**（Python 标准方案 `datasketch` 库）：不两两比对，牺牲少量召回换可扩展性。

### 1.5 脱敏的两个层级

1. **规则层**：正则——手机号、身份证、邮箱、银行卡等格式固定的 PII 都好抓
2. **模型层**：NER 识别姓名、地址等无固定格式的 PII（微软 Presidio、HanLP）

合规背景：《个人信息保护法》——脱敏不是技术洁癖，是法律要求。

### 1.6 统计报告 = 清洗的账本

报告三要素：**总量变化**（30→22）、**分类计数**（每条规则洗掉多少）、**抽样示例**（每类抽 2 条肉眼确认规则没误伤）。清洗不可回溯就是事故：原始数据永远保留，清洗产物另存。

### 1.7 常用工具阶梯（由浅到深）

| 层级 | 工具 | 定位 |
|---|---|---|
| L1 必须动手 | Python `re` 正则、pandas、Excel 肉眼核对 | 本节练习的主力 |
| L2 装着玩 | `chardet`（编码检测）、`langdetect`（语言识别）、`datasketch`（MinHash/LSH 近似去重） | 加练项 |
| L3 知道即可 | OpenRefine（交互清洗 GUI）、Great Expectations（数据质量断言）、cleanlab（标注质量检测） | 系统级工具的定位 |
| L4 面试谈资 | **data-juicer**（阿里开源 LLM 数据处理系统）、Dingo（LLM 语料质量规则）、NeMo Curator（NVIDIA） | 工业级大模型语料管线 |

本仓库边界：L1 写熟，L2 装着玩，L3/L4 概念即可。

### 埋雷清单（对答案用，做之前别看太细）

| 脏数据类型 | 条数 | 备注 |
|---|---|---|
| 空文本 / 纯空白 | 3 | 含全角空格（U+3000）1 条 |
| 精确重复（多余行） | 5 | 一组三胞胎 + 两组双胞胎 |
| 含手机号 | 3 | 脱敏，不删行 |
| 含身份证号 | 2 | 脱敏，不删行 |
| 含 HTML 标签 | 2 | 去噪，不删行 |
| 乱码 | 2 | 练习要求里没有，留作思考题 |
| 近重复（精确去重漏网） | 2 | id=14 与 id=23 只差一个尾随空格 |
| 字段内含换行 | 1 | id=24，考验 CSV 解析 |
| 半角逗号文本 | 1 | id=28，考验 CSV 引号 |

**预期结果**：30 条 →（去空 -3）→（精确去重 -5）→ **22 条**；脱敏 5 条、去噪若干条是"改文本"不是"删行"。

**编码提示**：CSV 是 UTF-8（无 BOM），pandas 默认参数可读；Excel 双击打开乱码属正常（Excel 按 ANSI 猜编码），别被吓到。

**加练**：跑 `make_dirty_corpus.py` 再生成一遍确认环境正常；改脚本扩到 100 条、埋新雷（URL、表情符号），洗自己造的数据。

## 三、课后练习

### 练习 1：脏语料清洗流水线（难度 2/5）

**业务背景**：客服系统导出的 `raw_corpus.csv` 什么妖魔鬼怪都有：空行、重复、手机号、身份证号、HTML 标签、乱码。洗成干净语料。

**技术要求**（`p1_corpus/p1_clean.py`）：
1. **去空**：`text` 为空或纯空白（含全角空格）的丢弃。
2. **精确去重**：完全相同的文本只留一条。
3. **脱敏**：正则替换手机号（1 开头 11 位）→ `"[PHONE]"`，身份证号（18 位）→ `"[ID]"`。
4. **去噪**：去掉 HTML 标签、连续空白压缩成单个空格。
5. **统计报告**：打印清洗前后条数、每类原因洗掉多少条、清洗后保存 `clean_corpus.csv`。

**提示**：先想清楚处理顺序（见 1.3）——顺序不同，报告数字不同。
