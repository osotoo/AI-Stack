### 首选总览书（留到第四阶段再看）
*   **《AI工程：大模型应用开发实战》（Chip Huyen 著）**
    *   **什么时候看**：等你用 Java 跑通了 RAG，需要建立全局架构观的时候看。这本书覆盖了模型选择、RAG、Agent、推理优化，是帮你建立架构师思维的总图。
*   **《大语言模型工程师手册：从概念到生产实践》（Paul Iusztin 等著）**
    *   **什么时候看**：等你开始做完整项目、需要写工程化代码（微调、量化、流水线部署）的时候看。里面有一个贯穿全书的实战项目。

### RAG 与 Agent 专项（留到第四阶段实战时当工具书）
*   **《基于RAG的大模型应用开发：问答系统、多模态系统与Agent开发实践》（宿永杰 著）**
    *   讲RAG原理、架构、优化、评估，带Dify和多模态实战。
*   **《大型语言模型应用实战：从Prompt Engineering到Agentic RAG与MCP》（陈仁政 著）**
    *   技术栈比较新，涵盖了Agentic RAG和MCP（Model Context Protocol）。

### 推理部署与性能优化（留到第五阶段或面试前看）
*   **《vLLM 与 SGLang：大模型高效推理双引擎实战》（李明飞 著）**
    *   市面上少有的专门讲vLLM的实战书，深入PagedAttention、连续批处理等核心机制。

### 免费的顶级开源资料（随时可翻）
*   **GitHub项目 `book-llm-infra`**：一本面向应用层工程师的开源书，涵盖Transformer工程师视角、GPU基础、vLLM深度剖析、量化、部署监控等。
*   **GitHub项目 `Awesome LLM Books`**：持续更新的LLM技术书籍清单。
