# 教学内容设计规范（tutorial-writing）

本仓库是学习仓库，文档的本质是教材。排版归 doc-style，表达归 google-dev-style，本规范管"怎么教"：内容按什么顺序出现、练习怎么设计、读者怎么确认自己学会了。

## 一、教学设计的三条底层原则

1. **目标先行**：写任何一节之前，先用一句话回答"读者读完这节能做什么新事情"。这句话决定内容取舍——帮不上这个目标的材料，再精彩也不放
2. **由已知到未知**：新概念必须挂在读者已经认识的东西上（本仓库的锚点：前面层学过的 Python、pandas、DataLoader、Ollama）。找不到锚点的概念，先补锚点
3. **一次一个概念**：一个小节只引进一个新概念。两个新概念互相依赖时，拆开，先教依赖的那个

## 二、讲解顺序（改编自加涅九事件）

每个知识小节按这个顺序组织，对应关系：

1. **引起注意 + 为什么学**：小节开头的人话段落——这个问题不解决会发生什么（对应：引起注意）
2. **告知目标**：开头就交代"读完你能做什么"（对应：告知目标）
3. **唤起旧知**：新概念出现时，用一句"还记得 p3 里的 collate_fn 吗"式的话挂上已有知识（对应：唤起旧知）
4. **呈现内容**：结论前置的讲解（对应：呈现内容）
5. **提供指导**：考点讲成故事和例子，代码块展示（对应：提供指导）
6. **引出练习**：课后练习，验收标准明确（对应：引出行为）
7. **反馈与评估**：自测题 + 可对照的答案位置（对应：提供反馈、评估）
8. **促进迁移**：加练/待补里留一个"换个场景还成立吗"的钩子（对应：促进保持和迁移）

## 三、概念讲解的规则

1. **是什么 → 为什么 → 怎么用 → 边界在哪**：四问齐全才算讲完一个概念。"边界在哪"最常被漏——去重能抓什么抓不住什么，就是边界
2. **示例先于抽象**：先看两条具体的脏数据，再总结"变换在前判等在后"的规则；不要反过来
3. **类比要标明是类比**：比喻帮助入门，但要指出比喻在哪里失效（"账本"类比统计报告成立，但账本不会自动记账）
4. **术语第一次出现必须定义**：SFT、DPO、PII 这类缩写，首次出现给中文全称；同一文档里术语保持同一个叫法
5. **警惕认知负荷**：一段话里新术语不超过两个；列表嵌套不超过两层；需要读者同时记三件事的操作，拆步骤

## 四、练习题设计规则

1. **难度阶梯**：同层练习从热身（照着做）到进阶（自己设计）到选做（迁移），标注难度（难度 n/5）
2. **业务背景先行**：每道题用两三句业务背景开头，让读者知道"在什么真实场景下会遇到这事"——练习题和裸题的区别就在这层皮
3. **验收标准可执行**：每道题写清"做完怎么算对"（能被 `datasets` 加载、统计数字对得上埋雷清单），不可验收的练习等于没有练习
4. **提示分级，不直接给答案**：提示分三级——指方向（"想想处理顺序"）、给骨架（关键函数签名）、给类似物（"和 p3 的 collate_fn 一个思路"）。答案骨架只在读者卡住时给
5. **埋认知雷**：刻意设计一个能暴露常见误解的坑（如近重复数据专坑"先去重"的顺序），并在埋雷清单里备好对答案的预期结果
6. **练习之间有依赖链**：前面的产出被后面的复用（validate 函数、清洗后的语料），让读者看到工程是连着的，但依赖链要在文档里写明

## 五、自测题设计规则

1. **考检索，不考重读**：自测题换角度提问，逼读者从记忆里提取，而不是回原文扫一眼（"为什么 A 要在 B 前面？举例说明"好于"A 在 B 前面对吗"）
2. **覆盖全部考点**：文中有几处（考点）标记，自测题至少对应每一处
3. **答案要可对照**：答案必须在上文明确存在，题干注明"翻回上文对照"
4. **混入一道应用题**：每节自测至少一道"用你自己工作里的例子说明 X"，把知识钩到读者自己的场景上

## 六、反模式（出现即返工）

1. **信息倾倒**：把知道的全写上，没有目标过滤——读完不知道能干什么
2. **只给代码不给为什么**：示例代码必须带"这段在干什么、为什么这么写"
3. **无验收的练习**：任务描述了一大堆，没说怎么算完成
4. **跳步**：用到了读者没学过的概念且不解释
5. **比喻失控**：通篇比喻但没有一处落到精确机制上
6. **术语漂移**：同一概念前后换叫法（一会儿"指令对"一会儿"问答对"）

## 七、写完后的自查清单

- 能用一句话说出这节的教学目标吗？
- 每个新概念有锚点（挂已学知识）吗？
- 有没有哪段一口气引进了两个以上新概念？
- 每道练习有业务背景和验收标准吗？
- 考点数量和自测题数量对得上吗？
- 读者做完这节，能向别人复述"这节解决了什么问题"吗？
