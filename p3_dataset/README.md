# p3_dataset — 数据工程（路线图 ②）

AI 流程的**起点**。模型的能力上限由数据决定——"有多少人工，就有多少智能"，本层负责把原始语料加工成能喂给微调的结构化数据集。

## 流程位置

- **上游**：无（起点）
- **下游**：`p4_finetune` —— 本层产出的数据集是微调的训练输入

## 子目录

| 子目录 | 内容 | 作用 |
|---|---|---|
| `p1_corpus/` | 语料采集与清洗 | 从公开资料/业务文档获取原始文本，去重、去噪、脱敏 |
| `p2_instruction/` | 指令对构造（SFT 数据） | 把语料整理成 instruction/input/output 三元组问答对 |
| `p3_preference/` | 偏好对构造（DPO 数据）【选学】 | 同一问题的多档回答并标注优劣，供偏好对齐训练用 |

## 学习深度要求

- **必须动手**：亲手构造 100 条指令对（Excel → JSONL），验收标准是能被 `datasets` 库加载
- **概念即可**：预训练语料的规模量级、工业级清洗去重流程
